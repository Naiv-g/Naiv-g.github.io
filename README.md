A dark, futuristic personal portfolio website showcasing my skills, projects, and experience as an **AI & Machine Learning Engineer**. Built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

---

## ✨ Features

- 🌌 **Animated starfield canvas background** with parallax scrolling
- 🖱️ **Custom cursor** with smooth ring-follow animation
- ⌨️ **Typewriter effect** cycling through roles
- 🃏 **3D tilt effect** on project and skill cards
- 📊 **Animated skill progress bars** triggered on scroll
- 🔢 **Counter animation** for hero stats
- 📱 **Fully responsive** — mobile menu with hamburger toggle
- ✨ **Glassmorphism** card design throughout
- 🎨 **Scroll reveal animations** (up, left, right)
- 📩 **Contact form** with simulated submission feedback
- 📄 **Resume download** button (navbar + contact section + mobile menu)

## 🚀 Running Locally

No build step needed — just open the file directly:

```bash
# Option 1: Open directly in browser
open index.html

# Option 2: Serve locally with Python
python -m http.server 8000
# Then visit http://localhost:8000

# Option 3: Use VS Code Live Server extension
# Right-click index.html → "Open with Live Server"
```

## 📦 Deploying

### GitHub Pages
1. Push this repo to a GitHub repository named `Naiv-g.github.io`
2. Go to **Settings → Pages → Source → main branch**
3. Your site will be live at `https://naiv-g.github.io`

### Vercel (Recommended)
1. Go to [vercel.com](https://vercel.com) and sign in with GitHub
2. Import this repository
3. Click **Deploy** — no configuration needed
4. Live in under 60 seconds ⚡
